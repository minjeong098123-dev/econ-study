# 경제소학회 스터디 홈페이지

공지사항·정보 공유·일정표·뉴스스크랩을 한곳에 모아 두는 페이지입니다.
스터디원 누구나 글을 올리고, 모두가 같은 내용을 봅니다.

---

## 설정 순서

키를 넣기 전에도 화면은 열리며, 위쪽에 안내 문구가 뜹니다.

### 1. Supabase 프로젝트 만들기

[supabase.com](https://supabase.com) 에서 가입하고 **New project** 를 누릅니다.
비밀번호를 하나 정하라고 하는데, 적어 두기만 하고 따로 쓸 일은 없습니다.
지역은 **Northeast Asia (Seoul)** 로 고르면 조금 빠릅니다. 무료 플랜으로 충분합니다.

프로젝트가 준비되는 데 1~2분 걸립니다.

### 2. 표 만들기

왼쪽 메뉴에서 **SQL Editor** 를 열고, `schema.sql` 을 통째로 복사해 붙여넣은 뒤 **Run** 을 누릅니다.
표 5개와 파일 저장소가 한 번에 만들어집니다. 여러 번 실행해도 괜찮습니다.

### 3. 주소와 키 넣기

**Project Settings → Data API** 에서 두 값을 복사해 `config.js` 에 넣습니다.

```js
SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGciOi...',
```

`anon` 키는 공개용이라 코드에 그대로 넣어도 됩니다.
**`service_role` 키는 절대 넣지 마세요.** 그 키는 모든 권한을 가집니다.

### 4. 열어보기

로컬 서버를 켜고 확인합니다. 폴더에서 터미널을 열고:

```bash
py -3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 들어갑니다. 끌 때는 `Ctrl+C` 입니다.

> `index.html` 을 두 번 눌러 여는 방식(`file://`)은 권하지 않습니다.

### 5. 올리기

정적 파일이라 GitHub Pages 에 그대로 올라갑니다.
레포에 push 하고 **Settings → Pages** 에서 브랜치를 지정하면
`https://<계정>.github.io/<레포>/` 주소가 생깁니다.

이 주소는 휴대폰에서도 열리고, 스터디원 모두가 같은 내용을 봅니다.

## 화면 구성

| 페이지 | 파일 | 내용 |
|---|---|---|
| 시작화면 | `index.html` | 왼쪽에 할 일이 적힌 달력, 오른쪽에 최근 공지 10개 |
| 공지사항 | `notice.html` | 검색 · 작성하기 · 최신순 목록 |
| 공지 작성 | `notice-write.html` | 제목 · 내용 · 파일. 상단 메뉴 없음 |
| 공지 보기 | `notice-view.html` | 수정 · 삭제 |
| 정보 공유 | `info.html` 외 2개 | 공지사항과 같은 구성 + 링크 첨부 |
| 일정표 | `schedule.html` | 왼쪽 달력, 오른쪽에 그 날 일정과 입력칸 |
| 뉴스스크랩 | `news.html` | 왼쪽 달력, 오른쪽 주차별 모아보기 |
| 스크랩 작성 | `news-write.html` | 제목 · 작성자 · 메모 · 주제 2개 · 파일. 상단 메뉴 없음 |
| 스크랩 보기 | `news-view.html` | 수정 · 삭제 |
| 주차 페이지 | `news-week.html` | 작성자별 주제 정리 + 발표자 랜덤 배정 |

| 공용 파일 | 역할 |
|---|---|
| `config.js` | 스터디 이름, 명단, Supabase 주소와 키 |
| `store.js` | 데이터 저장 — Supabase 를 다루는 곳은 여기뿐입니다 |
| `common.js` | 상단 메뉴, 달력, 파일 고르기 |
| `board.js` | 공지사항·정보 공유 공통 동작 |
| `style.css` | 전체 스타일 |
| `schema.sql` | 표·권한·파일 저장소 설정 |

## 명단 바꾸기

`config.js` 만 고치면 됩니다. 순서는 신경 쓰지 않아도 화면에는 늘 가나다순으로 나옵니다.

```js
MEMBERS: ['김민정', '김민성', '김초원', '신기현', '곽병서'],
```

## 뉴스스크랩

작성 페이지에서 **주제 2개와 기사 링크** 를 직접 적습니다.
그 주에 스크랩이 하나라도 올라오면 `n월 n주차` 가 자동으로 생기고,
그 페이지에서 작성자별로 주제가 정리돼 보입니다.

**발표주제정하기** 를 누르면 주제마다 발표자가 뽑힙니다.
자기가 쓴 주제는 맡지 않고, 인원수에 맞춰 되도록 고르게 나눕니다.
(5명이 두 개씩 올리면 한 사람당 두 개씩 돌아갑니다.)
뽑은 결과는 저장되므로 새로 고쳐도, 다른 사람이 봐도 그대로입니다.

## 주의사항

**로그인 기능이 없습니다.** 주소를 아는 사람은 누구나 글을 올리고 지울 수 있습니다.
스터디원끼리 주소를 공유해 쓰는 용도로는 충분하지만, 외부에 널리 공개할 페이지라면
Supabase Auth 를 붙이고 `schema.sql` 의 정책에서 `to anon, authenticated` 를
`to authenticated` 로 바꿔야 합니다.

**올린 파일은 공개 링크로 접근할 수 있습니다.** 민감한 자료는 올리지 마세요.

**글을 지우면 딸린 첨부파일도 같이 지워집니다.** 되돌릴 수 없습니다.
다만 파일 주소를 이미 알고 있던 사람은 한 시간 정도 더 내려받을 수 있습니다.
Supabase 가 파일을 한 시간 동안 임시 보관(캐시)하기 때문입니다.
